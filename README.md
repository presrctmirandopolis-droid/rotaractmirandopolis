# Rotaract Club de Mirandópolis — Portfólio Web

Site institucional/comercial em HTML, CSS e JavaScript puro, com estética criativa, interativa e profissional.

## Estrutura
- `index.html` — estrutura e conteúdo da página
- `style.css` — identidade visual, responsividade e animações
- `script.js` — interações, menu mobile, cursor, reveal on scroll e efeitos
- `assets/logo.png` — logo enviada pelo cliente

## Como abrir
Basta abrir `index.html` em um navegador moderno.

## Personalização recomendada
1. Trocar o e-mail de contato no `index.html`.
2. Substituir os cards da seção "Portfólio" pelos projetos reais do clube.
3. Adicionar links oficiais das redes sociais do Rotaract Club de Mirandópolis.
4. Se desejado, adicionar fotos reais dos projetos na pasta `assets`.
